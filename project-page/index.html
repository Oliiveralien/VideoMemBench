01 / THE BENCHMARK

Beyond answering one question at a time.

A useful video conversation is connected: later questions revisit what happened earlier, or build on an answer already given. VideoMemBench measures this ability to retrieve and reuse information across turns—in-context video memory.

01 / EPISODIC DEPENDENCY

Remember what you have seen.

A later question can return to a scene, object, or event discussed earlier in the conversation.

The model must reconnect that reference with the right visual episode and retrieve the relevant details.

EpiDepAccAccuracy on turns that revisit an earlier visual episode.

02 / ANSWER DEPENDENCY

Remember what you have said.

A later question can build on an answer the model has already given.

That earlier answer becomes part of the reasoning. A correct response earns credit only when its full answer-dependency chain is also correct.

AnsDepAccCredit for a correct response and its answer ancestors.

03 / EVALUATION

The same video. The model’s own history.

Visual input stays fixed; the conversation unfolds one turn at a time.

iEvaluation protocolFixed input, sequential conversation, answer grading

  1. Fix the visual input

    Uniformly sample 128 timestamped frames once per video. Reuse the same frames for every model and every turn.

  2. Roll out the dialogue

    Ask questions in order, retaining the model’s own full historical responses. Ground-truth answers are not inserted into history.

  3. Grade each response

    Extract option letters for multiple-choice questions. Grade open-ended answers with GPT-5.4 mini under the paper’s binary semantic criterion.

iTurnAccTurn accuracy
Evaluation subset
All conversation turns.
Credit rule
A turn receives credit when the current response is correct.
iEpiDepAccEpisodic dependency accuracy
Evaluation subset
Turns with at least one Episodic parent.
Credit rule
The current response must be correct. Credit is independent of whether the parent responses were correct.
iAnsDepAccAnswer dependency accuracy
Evaluation subset
Turns with at least one Answer parent.
Credit rule
The current response and every recursive ancestor reached through Answer edges only must all be correct. Episodic edges are not followed when tracing these ancestors.
iOverallEqual-weight mean of the three metrics

(TurnAcc + EpiDepAcc + AnsDepAcc) / 3

The three metrics contribute equally to the overall score. All scores are reported as percentages; higher is better.

Run the evaluation

Frame preparation, self-rollout, answer grading, and dependency-aware scoring.
